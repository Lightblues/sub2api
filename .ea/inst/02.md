# 镜像构建流程
使用 /root/sub2api/src/Dockerfile 多阶段构建：
Stage 1 - 前端构建：Node 24 + pnpm，产出静态文件
Stage 2 - 后端构建：Go 1.26.2，嵌入前端 dist，编译单二进制 /app/sub2api
Stage 3 - 从 postgres:18-alpine 提取 pg_dump/psql（备份工具）
Stage 4 - 最终运行时：alpine 3.21 精简镜像

# 相关命令

docker build -t sub2api:eason .
cd /root/sub2api && docker compose up -d sub2api
